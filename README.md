# check_your_ass_ios

Tiny iOS openFrameworks app: records a run of frames from the camera, then lets you scrub back through them by swiping. Handy for checking your back without a mirror.

## Build

- Written for OF 0.7.3 iOS (`testApp`, `ofxiPhone`), so it will need updating for current ofxiOS.
- Generate the project with projectGenerator (iOS template).

Old code (2013), kept for reference.
